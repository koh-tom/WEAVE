# 🌱 WEAVE `kusa_node` 実デモ録画・展示ガイド

このガイドでは、`kusa_node.wasm` のリアルタイム・イベント処理および安全機能（自動非表示タイマー・クールダウン制約）を動画録画や学術・展示ブース（常時デモ）で実演する手順を解説します。

---

## 🎥 1. デモのハイライト（アピールするポイント）

1. **Wasmサンドボックスによるストリーミング処理**:
   - Twitchチャットコメントをリアルタイム解析し、3秒間に10回以上の「草」「w」を検出した時のみOBSオーバーレイを起動。
2. **Web Dashboard の仮想 OBS プレビュー**:
   - 画面上部に OBS 仮想プレビューが表示され、`kusa_node` が `core.obs.request.SetSceneItemEnabled(true)` をパブリッシュした瞬間に **🌱ｗｗｗｗ 草草草 ｗｗｗｗ** のアニメーションエフェクトがリアルタイム表示されます。
3. **10秒自動非表示 & 15秒クールダウンの安全性**:
   - 起動から10秒後に自動でオーバーレイが非表示 (`sceneItemEnabled: false`) に変化。
   - 最初の起動から15秒間は、いくら「草」が連投されても連打スパムを防ぐためにクールダウン（ガード）が機能します。
4. **トポロジー & トレースログ**:
   - ダッシュボードの「システムトポロジー」タブで `TwitchAdapter -> kusa_node -> ObsEgress` のイベントフローを視覚的に確認できます。

---

## 🚀 2. 実行手順

### 方式 A: Web UI からインタラクティブに実演（手動録画向け・OBS不要）

```bash
./demo/run_kusa_demo.sh
```

1. ブラウザで **`http://localhost:3030`** を開きます。
2. 画面左側の **「🌱 草ラッシュ (10連発)」** ボタンをクリックします。
3. 仮想 OBS プレビューで草エフェクトが起動し、ログに `SetSceneItemEnabled: true` が流れる様子を録画します。
4. 10秒経過すると自動非表示タイマーが作動し、`SetSceneItemEnabled: false` が発行されます。
5. 直後に「草ラッシュ」を連打しても、15秒クールダウンが機能して再発動しない安全性を示せます。

---

### 方式 B: 自動シナリオ再生（ノーカット全自動録画向け・OBS不要）

```bash
./demo/run_kusa_demo.sh --auto
```

- 事前定義されたチャットシナリオ (`demo/scenarios/kusa.jsonl`) が自動再生され、以下の流れが約30秒間で再現されます：
  - **0〜1秒**: 1回目の草バースト → **エフェクト ON**
  - **11〜12秒**: 10秒経過による **自動 OFF** + クールダウン中の2回目草バースト → **ガード機能で無視**
  - **17秒**: 15秒クールダウン解除後の3回目草バースト → **エフェクト ON 再起動**

---

### 方式 C: ブース展示用・実 OBS Studio 連携エンドレスデモ（常時展示向け）

本物の OBS Studio と接続し、実際に OBS 画面上の「Overlay」ソースを表示・非表示させながら、無限ループでデモを流し続ける設定です。

```bash
# OBS のパスワード等を指定して起動 (環境変数またはデフォルト 127.0.0.1:4455)
OBS_PASS="your-obs-password" ./demo/run_booth_demo.sh
```

- **実 OBS 通信**: `ObsEgressNode` (Zig Native Wrapper) が OBS WebSocket v5 RPC を構築して本物の OBS を制御。
- **連続ループ**: Twitch シナリオが自動でループ再生され、ブース展示中ずっと自動で発火 → 自動非表示 → クールダウン保護 → 再発火 を繰り返します。
- **マルチ画面展示**: モニター 1 に OBS Studio 画面、モニター 2 に WEAVE Dashboard (`http://localhost:3030`) を配置すると非常に映える展示になります。

---

## 📊 3. ダッシュボード構成要素

- **仮想 OBS プレビュー**: OBS Studio が無くても `SetSceneItemEnabled` の発火をビジュアルとカウントダウン付きで再現
- **チャットシミュレータ**: 10連発ボタンおよび任意のメッセージ送信機能
- **リアルタイム・イベントストリーム**: イベントバスを流れる全トピックの生のJSONペイロードを監視
- **システムトポロジー**: Dynamic Graph によるノード間の Pub/Sub 結合の可視化
